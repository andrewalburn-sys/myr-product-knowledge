**Purpose:** A reusable working library for evaluating where AI should matter in the MyRecipes experience, how it should show up, and what to build first.

## Shared Template

Each framework file follows the same pattern so it can be reused in future planning:

- `Purpose`: what decision this framework is meant to support
- `Why it matters here`: why the framework is useful for MyRecipes specifically
- `How to use it`: the working method for a workshop or strategy pass
- `Inputs`: source materials needed to run the framework well
- `Evaluation lens`: what criteria or scoring dimensions to apply
- `MyRecipes application`: the framework filled in using current strategy work
- `Strategic implications`: what MyRecipes should do as a result
- `Decision prompts`: reusable prompts for future sessions
- `Output artifact`: what final answer or document this framework should produce

## Core Strategic Throughline

Across the library, the same conclusion should keep getting pressure-tested:

- MyRecipes should not add AI indiscriminately across the product.
- MyRecipes should build an intelligent cooking companion across the full journey.
- The intelligence layer should remain unified beneath the product.
- The user-facing role of AI should change by context:
  - Planning: decision engine
  - Shopping: constraint optimizer
  - Cooking: real-time guide
  - Learning: memory and improvement loop

## Decision Rules

Use these rules when applying any framework in this folder:

1. Prioritize places where intelligence removes friction, not places where AI merely decorates an existing workflow.
2. Treat the largest audience segment, the Established Home Cook, as the trust bar for invisible AI.
3. Favor answers over options when the user is under constraint.
4. Favor transparent reasoning over opaque personalization when the stakes are high.
5. Design for recovery, not just the ideal path.
6. Build one intelligence system with multiple context-specific surfaces.

## What "Best-In-Class" Means Here

For MyRecipes, best-in-class does not mean the most visible AI. It means:

- the least friction from idea to dinner,
- the strongest trust at the moment of decision,
- the smartest adaptation when plans break,
- and the highest sense that the product understands the user without making them do extra work.
