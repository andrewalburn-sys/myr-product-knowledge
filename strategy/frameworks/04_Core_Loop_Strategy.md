# 04 Core Loop Strategy

## Purpose

Define the dominant product loop MyRecipes should strengthen so AI becomes part of the product's compounding system rather than a disconnected add-on.

## Why It Matters Here

If AI sits outside the product loop, it becomes a gimmick. If AI improves the loop, it becomes the product. MyRecipes needs a loop that connects planning, cooking, and learning so every successful use makes the next one easier and more personalized.

## How To Use It

1. Identify the repeat behavior the product wants to encourage.
2. Map the inputs, user actions, and outputs at each loop stage.
3. Define how the system gets smarter after each cycle.
4. Use the loop to evaluate whether a new feature strengthens or distracts from the core product.

## Inputs

- Journey stages and key moments of truth
- Existing opportunities
- Persona behaviors and repeat patterns
- Personalization and memory ambitions

## Evaluation Lens

For each step in the loop, assess:

- `User value`: what the user gets immediately
- `System learning`: what the product learns
- `Repeat pull`: why the user comes back
- `AI role`: how intelligence improves the next cycle

## MyRecipes Application

### Recommended Core Loop

`Plan -> Cook -> Reflect -> Improve -> Plan better next time`

### Loop Breakdown

| Loop step | User value | System learning | AI role |
| --- | --- | --- | --- |
| Plan | A realistic recommendation or weekly plan | Learns constraints, preferences, appetite patterns, and intent mode | Decision engine and planner |
| Cook | Guidance, pacing, substitutions, and confidence | Learns friction points, successful swaps, timing behavior, and drop-off points | Real-time guide and recovery engine |
| Reflect | Save, rate mentally or explicitly, repeat, adapt | Learns what was actually cooked, liked, skipped, or modified | Preference memory |
| Improve | Better personalization and less friction next time | Updates taste map, household fit, and confidence thresholds | Invisible intelligence layer |

### Why This Loop Fits MyRecipes

- It supports all four personas without forcing them into the same interface.
- It turns usage into compounding knowledge rather than isolated sessions.
- It treats cooking as a living process, not as a one-time content view.
- It gives the product a direct route from utility to loyalty.

### Anti-Patterns To Avoid

- `Browse -> Save -> Forget`: creates content accumulation, not progress
- `Ask AI -> Get answer -> Leave`: useful in the moment, but weak as a product loop
- `Search -> Read recipe -> Cook elsewhere`: keeps MyRecipes as a recipe destination, not a companion

## Strategic Implications

- The product should capture learning from both decision and execution.
- Saved recipes should become part of the improvement loop, not just a static collection.
- Post-cook signals matter because they power better future planning.
- AI features should be evaluated by whether they strengthen the loop, not just whether they sound compelling.

## Decision Prompts

- Does this feature increase the chances the user comes back smarter next time?
- What does the system learn if the user succeeds or fails here?
- Is this feature part of the loop or sitting outside it?
- Does the loop get stronger after each use?

## Output Artifact

A core-loop map that shows how MyRecipes compounds user value and system intelligence over repeated cooking sessions.
